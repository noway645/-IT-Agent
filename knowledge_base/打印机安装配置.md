# 打印机安装配置

适用场景：星辰科技员工在办公区连接网络共享打印机或 USB 本地打印机，进行日常打印、复印、扫描。公司打印机统一通过打印服务器 `\\printserver` 管理，建议使用网络共享方式安装。

## 打印机清单

| 共享路径 | 型号 | 位置 | 功能 | 备注 |
| --- | --- | --- | --- | --- |
| \\printserver\HP-LaserJet | HP LaserJet Pro M404 | 3F 办公区 A 区 | 黑白打印 | 默认黑白机 |
| \\printserver\HP-ColorJet | HP Color LaserJet Pro M454 | 3F 办公区 B 区 | 彩色打印 | 彩色需 OA 申请 |
| \\printserver\Canon-iR | Canon imageRUNNER 2625i | 4F 综合部 | 复印/扫描/打印 | 支持双面 |
| \\printserver\HP-Finance | HP LaserJet Enterprise M611 | 5F 财务部 | 黑白打印 | 仅财务部授权 |

> 打印机命名规则：`\\printserver\<品牌-型号简称>`，所有员工默认可连接除财务专用机外的全部打印机。

## Windows 安装步骤（推荐方式）

1. 按 `Win + R` 打开运行窗口，输入 `\\printserver` 回车。
2. 弹出认证窗口时，用户名填 `company\firstname.lastname`，密码填域密码，勾选"记住我的凭据"。
3. 资源管理器列出所有共享打印机，双击 `HP-LaserJet`。
4. Windows 自动下载并安装驱动，弹出打印队列窗口即表示安装成功。
5. 设置默认打印机：设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 选中 `HP LaserJet Pro M404 (副本 1)` → 设为默认值。

## 通过"添加打印机"安装（备选）

1. 设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 添加设备。
2. 等待搜索完成后点击"我需要的打印机不在列表中"。
3. 选择"按名称选择共享打印机"，输入 `\\printserver\HP-LaserJet`，点击"下一步"。
4. 系统自动匹配驱动，按提示完成安装。

## macOS 安装步骤

1. 系统设置 → 打印机与扫描仪 → 添加打印机。
2. 地址栏输入 `printserver.company.com`，协议选择 `Line Printer Daemon - LPD`。
3. 队列名称填 `HP-LaserJet`，名称自定义。
4. 使用栏选择"选择软件"，搜索 `HP LaserJet Pro M404`，选中后点击"添加"。
5. 在选项中按需启用双面打印单元，点击"确定"完成。

## 打印测试与日常使用

1. 打开任意文档（如 Word），按 `Ctrl + P`，确认默认打印机为 `HP-LaserJet`。
2. 点击"打印"，到打印机旁取件。
3. 复印/扫描：在打印机面板插入原件，选择"复制"或"扫描到邮件/USB"。

## 配置参数

- 打印服务器：`\\printserver`（IP：10.10.2.20）
- 驱动获取：自动从服务器拉取，无需手动下载
- 纸张：默认 A4，纸盒 1 为普通纸，纸盒 2 为厚纸
- 双面打印：默认开启，单面请在打印对话框手动关闭

## 常见问题

**Q1：双击打印机提示"无法连接，操作无法完成"？**
A：多为未保存凭据或与打印服务器网络不通。请先用 `Win+R` 输入 `\\printserver` 测试，能弹出目录说明连通。若提示认证失败，进入"控制面板 → 凭据管理器 → Windows 凭据"删除旧记录后重新输入 `company\firstname.lastname`。

**Q2：打印任务发出但打印机不出纸？**
A：先在打印机面板确认不缺纸、无卡纸、状态为"就绪"；再到电脑"设备和打印机 → 查看打印队列"，如有积压任务右键"以管理员身份重新开始"。彩色机如未授权会显示"已暂停"，请通过 OA 申请彩色权限。

**Q3：打印乱码或排式错乱？**
A：驱动版本不一致，删除打印机后重新通过 `\\printserver` 安装；或临时在打印对话框选择"打印为图像"。Mac 用户请确认选用了正确的 PostScript 驱动。

**Q4：如何扫描文件到邮箱？**
A：在 Canon-iR 面板上选择"扫描 → 发送到我"，输入工号后从通讯录选择本人邮箱，放置原稿后按"开始"。如未配置个人邮箱地址，请提交工单至 IT 服务台 8000 补录。
