# 远程办公接入

适用场景：星辰科技员工因居家办公、出差、客户现场支持等情况需要在公司外部访问内部系统（OA、邮件、文件服务器、业务系统）时，按本指南完成远程接入。远程办公需提前开通 VPN 权限并配置好相关客户端。

## 远程办公所需工具

| 工具 | 用途 | 获取方式 |
| --- | --- | --- |
| EasyConnect VPN 客户端 | 接入公司内网 | https://vpn.company.com |
| 企业邮箱客户端（Outlook/Foxmail） | 收发邮件 | 参考《邮箱客户端设置》 |
| 浏览器 | 访问 OA、Web 邮箱、业务系统 | 任意现代浏览器 |
| 远程桌面（RDP） | 远程登录公司办公电脑 | Windows 自带 |
| 企业微信 | 即时沟通与 IT 服务大厅 | 应用商店下载 |

## 准备工作

1. 确认已开通 VPN 权限：未开通者在 OA 提交"VPN 权限申请"，由直属主管与 IT 审批。
2. 确认域账号密码有效：遗忘密码参考《OA 系统密码重置》完成重置，密码同步至 OA、邮箱、VPN。
3. 确认办公电脑已开启"允许远程桌面"：右键"此电脑 → 属性 → 远程设置 → 允许远程连接到此计算机"。
4. 记录办公电脑主机名：命令行 `hostname` 查询，例如 `PC-FIN-023`，或向 IT 查询其内网 IP。

## 远程办公标准流程

1. **连接 VPN**
   - 启动 EasyConnect，服务器地址 `vpn.company.com`，域账号密码登录。
   - 完成企业微信二次认证，客户端托盘显示"已连接"。
   - 详细步骤见《VPN 安装与使用》。

2. **访问 OA 与业务系统**
   - 浏览器打开 https://oa.company.com ，域账号登录。
   - OA 密码与域账号密码一致，遗忘参考《OA 系统密码重置》。
   - 其他业务系统通过 OA 工作台"应用中心"跳转，单点登录免重复输入密码。

3. **收发邮件**
   - 推荐 Web 邮箱：https://mail.company.com ，域账号登录即可。
   - 客户端配置见《邮箱客户端设置》；VPN 下 IMAP/SMTP 配置与公司内一致。

4. **访问文件服务器**
   - VPN 连接后，`Win + R` 输入 `\\fileserver` 访问共享盘。
   - 个人网盘 H 盘映射：`\\fileserver\home$\用户名`。
   - 详细步骤与权限见《文件服务器访问》。

5. **远程登录公司办公电脑（可选）**
   - `Win + R` 输入 `mstsc` 打开远程桌面。
   - 计算机名填办公电脑主机名（如 `PC-FIN-023`）或内网 IP（10.10.x.x）。
   - 用户名 `company\firstname.lastname`，密码填域密码。
   - 连接成功后可像在公司一样操作办公电脑，访问内网所有资源。

## 居家办公网络要求

- 带宽：下行 ≥20Mbps，上行 ≥5Mbps。
- 延迟：到 vpn.company.com 的 ping 延迟建议 <50ms。
- 优先使用有线网络，无线需确保信号稳定。
- 不要使用公共 WiFi（咖啡馆、机场）直接连 VPN，存在中间人攻击风险。

## 常见问题

**Q1：VPN 连上了，但 OA 打不开？**
A：先 `ping 10.10.1.1` 确认内网可达；能 ping 通则检查浏览器代理设置（应关闭代理）；尝试用 IP 访问 https://10.10.5.20 ；若仍打不开，可能是 DNS 解析问题，将 DNS 手动设为 10.10.1.10。仍不行请联系 IT 服务台 8000。

**Q2：远程桌面提示"无法连接，网络错误"？**
A：确认 VPN 已连接且办公电脑处于开机状态（远程桌面无法唤醒关机电脑）；核对主机名拼写；公司电脑需已开启远程桌面并接入内网。如电脑已关机，可联系同办公室同事协助开机，或申请 IT 远程唤醒（需电脑支持 WoL）。

**Q3：远程办公时 OA 密码过期了怎么办？**
A：OA 密码与域账号统一，过期后无法登录 VPN。请通过手机企业微信"IT 服务大厅 → OA 密码重置"自助修改（需人脸识别），新密码即时生效；或联系 IT 服务台 8000 人工重置。详见《OA 系统密码重置》。

**Q4：远程办公收发大附件很慢？**
A：VPN 下传输受本地网络与加密开销影响。建议：1）大文件先存到个人网盘 H 盘，发链接而非附件；2）附件超过 25MB 直接使用 OneDrive 企业版共享链接；3）非紧急邮件错峰发送。VPN 下频繁断线请参考《办公网络故障排查》网络稳定性章节。
