# 杀毒软件安装

适用场景：星辰科技员工在公司办公电脑（Windows / macOS）上安装公司统一部署的企业级杀毒软件，保障终端免受病毒、勒索软件、恶意程序侵害。公司禁止员工私自安装未经 IT 授权的安全软件。

## 软件信息

- 软件名称：火绒企业版终端安全管理（Huorong Enterprise）
- 管理控制台：https://edr.company.com
- 授权方式：域账号自动绑定，每台终端一个授权席位
- 部署范围：所有加入域的办公电脑，新装机默认已预装
- 病毒库更新：每小时自动同步，无需手动操作

## 安装前检查

1. 确认电脑已加入 COMPANY 域（右键"此电脑 → 属性"查看域状态）。
2. 卸载个人版杀毒软件（如 360 个人版、火绒个人版、腾讯电脑管家），避免冲突。
3. 关闭其他安全软件的实时防护。
4. 确认系统时间正确（与公司 NTP 同步），否则授权校验会失败。

## Windows 安装步骤

1. 浏览器访问 https://edr.company.com ，使用域账号登录。
2. 首页点击"终端安装包下载" → 选择"Windows 客户端（64 位）"，下载 `HuorongEnterprise_Setup_x64.exe`。
3. 右键安装包"以管理员身份运行"，安装向导自动检测环境。
4. 接受许可协议，安装路径保持默认 `C:\Program Files\Huorong\Enterprise`，点击"下一步"。
5. 在"控制中心地址"页面，服务器地址已预填 `edr.company.com`，端口 `443`，无需修改，点击"下一步"。
6. 安装完成后，客户端自动连接控制中心并绑定当前域账号，右下角托盘出现蓝色火绒图标。
7. 右键托盘图标 →"查看状态"，显示"已连接、病毒库最新、实时防护已开启"即安装成功。

## macOS 安装步骤

1. 访问 https://edr.company.com 下载 macOS 客户端 `HuorongEnterprise.dmg`。
2. 双击挂载，将火绒图标拖入"应用程序"文件夹。
3. 首次启动若提示"无法验证开发者"，进入"系统设置 → 隐私与安全性"，点击"仍要打开"。
4. 系统会要求授予"完全磁盘访问权限"和"系统扩展"权限，按提示在"系统设置"中逐一授权。
5. 控制中心地址自动填充 `edr.company.com`，使用域账号登录绑定。
6. 菜单栏出现火绒图标，状态显示"受保护"即完成。

## 日常使用与扫描

1. 全盘扫描：右键托盘图标 →"病毒查杀 → 全盘扫描"，建议每月一次，耗时约 30–60 分钟。
2. 闪电扫描：日常使用"快速扫描"，5 分钟内完成常见位置检查。
3. U 盘接入时自动扫描，发现威胁会弹窗拦截并隔离。
4. 查看隔离区：客户端主界面 →"隔离区"，可还原误报文件（需 IT 审批）。

## 配置参数

- 控制中心：https://edr.company.com（IP：10.10.4.10）
- 客户端端口：443（HTTPS）
- 病毒库更新频率：每小时
- 实时防护：默认开启文件监控、网络监控、行为监控
- U 盘防护：插入即扫描
- 隔离区保留：90 天

## 常见问题

**Q1：安装时提示"控制中心连接失败"？**
A：检查网络是否在公司内网或 VPN 已连接；命令行 `ping edr.company.com` 应解析到 10.10.4.10。若 ping 通但安装仍失败，确认系统时间是否准确（误差超过 5 分钟会导致证书校验失败），同步时间后重试。

**Q2：托盘图标变红，提示"实时防护已关闭"？**
A：可能被其他安全软件冲突关闭。先卸载 360、电脑管家等第三方安全软件，重启后客户端会自动恢复实时防护。若仍为红色，右键托盘 →"修复"→"一键修复"，或卸载重装客户端。

**Q3：火绒误删了我的工作文件？**
A：打开客户端 →"隔离区"，找到被隔离的文件，点击"还原"并勾选"加入白名单"。还原后该文件与所在目录将不再被扫描。如隔离区为空或文件已过期，请在 30 天内联系 IT 服务台 8000 从备份恢复。

**Q4：可以自己安装其他杀毒软件吗？**
A：不可以。公司终端安全策略要求统一使用火绒企业版，私自安装其他安全软件会触发告警并可能被远程卸载。如认为火绒漏报，可将样本提交至 it@company.com，由 IT 安全组分析并更新策略。
