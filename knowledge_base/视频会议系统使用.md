# 视频会议系统使用

适用场景：星辰科技员工使用公司视频会议系统进行内部会议、跨部门协作、客户沟通与远程培训。公司会议平台为腾讯会议企业版，会议室配备硬件终端，支持桌面客户端、网页、移动端、会议室多种接入方式。

## 会议平台信息

- 平台名称：腾讯会议企业版
- 企业 ID：StarTech（星辰科技）
- 客户端下载：https://meeting.tencent.com/download
- 会议入口：客户端、企业微信"会议"应用、会议室硬件
- 个人会议号：每位员工自动分配 9 位会议号，可在客户端"个人会议室"查看
- 单会议上限：300 人同时在线，最长 24 小时

## 桌面客户端安装与登录

1. 浏览器访问 https://meeting.tencent.com/download ，下载 Windows 或 macOS 客户端。
2. 安装完成后启动，登录方式选择"企业微信登录"。
3. 自动跳转企业微信完成授权，回到客户端显示本人姓名与"星辰科技"企业标识。
4. 登录后建议完成音视频测试：点击右上角设置图标 →"音频"和"视频"测试麦克风、扬声器、摄像头。

## 发起会议

1. 客户端首页点击"快速会议"。
2. 选择是否开启摄像头、麦克风，点击"进入会议"。
3. 进入会议后点击"邀请"，可：
   - 复制会议号与链接，发送至企业微信或邮件。
   - 直接从企业微信通讯录选择同事邀请。
4. 如需预约周期会议：首页点击"预定会议"→ 设置主题、时间、周期（每日/每周/每月）、参会人 → 点击"预定"。
5. 预定成功后会议链接自动同步到企业微信日历与 Outlook 日历。

## 加入会议

1. **客户端加入**：首页点击"加入会议"，输入 9 位会议号与姓名，点击"加入"。
2. **链接加入**：点击他人分享的会议链接，自动唤起客户端加入。
3. **企业微信加入**：企业微信收到会议邀请卡片，点击"加入"即可。
4. **电话拨入**：拨打 400 电话（会议邀请中提供）+ 输入会议号，仅音频接入。

## 会议室硬件使用

公司会议室配备腾讯会议 Rooms 硬件终端，含触控大屏、摄像头、麦克风阵列。

1. 进入会议室，触控屏自动亮起，显示"加入会议 / 即时会议"。
2. 扫码登录：用企业微信扫描屏幕二维码，绑定会议室与本人账号。
3. 发起会议：点击"即时会议"，或输入会议号加入既有会议。
4. 投屏：会议室大屏支持无线投屏，电脑安装腾讯会议客户端后，会议中点击"共享屏幕"→"共享无线投屏"，输入屏幕显示的 6 位投屏码即可。
5. 会议结束：点击"结束会议"，离开后请关闭大屏与摄像头电源。

## 会议中常用功能

1. **静音/取消静音**：点击底部麦克风图标，或按 `Alt + M`（主持人可全体静音）。
2. **共享屏幕**：点击"共享屏幕"，选择整个屏幕或单个窗口；共享时勾选"共享电脑声音"可播放音频。
3. **聊天**：点击"聊天"，可发送文字给所有人或指定参会人。
4. **录制**：主持人点击"录制"→"云录制"，录制文件存于企业云盘，会后自动生成链接发至主持人企业微信。
5. **会议纪要**：开启"AI 字幕"与"实时转写"，会议结束后可下载转写文本。

## 配置参数

- 平台：腾讯会议企业版

## 常见问题

**Q1：会议中对方听不到我的声音？**
A：首先确认麦克风未静音（图标无斜线）；点击设置 →"音频"，检查麦克风设备选择正确；测试麦克风时说话应看到音量条跳动。若仍无声，拔插 USB 麦克风或重启客户端；笔记本电脑检查是否被其他软件（如语音助手）占用麦克风权限。

**Q2：共享屏幕后参会人看不到内容？**
A：确认共享时选择了正确的屏幕或窗口；macOS 需在"系统设置 → 隐私与安全性 → 屏幕录制"中授权腾讯会议。若共享的是扩展显示器，请选择"整个屏幕"而非"窗口"。如涉及播放视频，勾选"共享电脑声音"并选择"视频优化"。

**Q3：会议室硬件无法登录或投屏失败？**
A：扫描二维码登录失败时，确认企业微信已更新至最新版本且已加入"星辰科技"企业。投屏失败先检查电脑与会议室是否在同一网络（应为 Corp-WiFi）；输入投屏码后等待 5 秒，若超时重新生成投屏码。硬件故障（大屏不亮、摄像头无图像）请拨 IT 服务台 8000 报修。

**Q4：会议录制找不到了？**
A：云录制默认保存到企业云盘 /recordings 目录，会议结束后约 10 分钟生成。主持人可在客户端"会议 → 历史会议 → 录制"查看与下载，链接也会推送至企业微信。如超过 30 分钟仍未生成，或录制超过 90 天被清理，请联系 IT 服务台 8000 协助查询。
