# VPN 安装与使用

适用场景：星辰科技员工在公司外部（家中、出差、客户现场）需要访问 OA、文件服务器、内网业务系统等内部资源时，通过 SSL VPN 安全接入公司内网。VPN 仅授权给正式员工，离职即回收。

## 准备工作

1. 确认已开通 VPN 权限：新员工入职时由部门行政在 OA 提交"VPN 权限申请"，IT 审批通过后开通。
2. 准备域账号与密码（与公司电脑登录密码一致）。
3. 确保本地网络畅通，建议带宽 10Mbps 以上。

## Windows 安装步骤

1. 浏览器访问 https://vpn.company.com ，页面出现证书警告时点击"高级 → 继续前往"。
2. 输入域账号、密码登录后，系统自动检测客户端，首次登录点击页面顶部"下载 Windows 客户端"，下载 `SangforAccessClient.exe`。
3. 双击安装包，按向导默认下一步完成安装，安装完成后桌面出现"EasyConnect"图标。
4. 启动客户端，服务器地址填写 `vpn.company.com`，点击"前往"。
5. 输入域账号、密码，点击登录；如开启二次认证，输入企业微信推送的 6 位验证码。
6. 客户端最小化到托盘并显示"已连接"，浏览器访问 http://oa.company.com 可打开即表示接入成功。

## macOS 安装步骤

1. 访问 https://vpn.company.com 下载 macOS 客户端 `EasyConnect.dmg`。
2. 双击挂载后，将 EasyConnect 拖入"应用程序"文件夹。
3. 首次启动若提示"无法验证开发者"，进入"系统设置 → 隐私与安全性"，点击"仍要打开"。
4. 服务器地址填 `vpn.company.com`，登录流程同 Windows。

## 移动端使用

1. 在应用商店搜索并安装"EasyConnect"（深信服）。
2. 打开 App，服务器地址填 `vpn.company.com`，账号密码登录。
3. 登录后可通过 App 内置门户访问 OA、邮件等内网应用。

## 配置参数

- VPN 网关地址：https://vpn.company.com
- 协议：SSL VPN（HTTPS 443）
- 客户端：EasyConnect（深信服）
- 接入后内网 IP 段：10.10.200.x
- 二次认证：企业微信扫码 / 推送验证码

## 常见问题

**Q1：客户端登录提示"账号未授权 VPN 服务"？**
A：说明域账号未开通 VPN 权限或已过期。请在 OA 提交"VPN 权限申请"流程，由直属主管与 IT 审批。临时需求可拨 IT 服务台 8000 加急处理。

**Q2：连接成功但访问内网很慢或时断时续？**
A：优先切换到更稳定的网络（如有线或 4G/5G 热点）；关闭本地占用带宽的下载、视频应用；在客户端"设置"中开启"TCP 加速"。仍无改善请记录 `ping 10.10.1.1` 的丢包率反馈给 IT。

**Q3：登录后部分内网站点打不开？**
A：可能是路由未下发。右键托盘客户端 →"资源访问"确认对应应用在授权列表中；若列表为空，说明权限未下发，请在 OA 提交权限变更申请。

**Q4：换电脑后提示"账号已在其他设备登录"？**
A：VPN 不允许同一账号多设备同时在线。请用原设备正常注销，或登录 https://vpn.company.com 管理门户自行下线其他会话。如原设备丢失，请联系 IT 服务台强制下线。
