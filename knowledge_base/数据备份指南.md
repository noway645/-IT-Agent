# 数据备份指南

适用场景：星辰科技员工对个人工作文档、项目资料、邮件等重要数据进行备份，防止因设备故障、误删、勒索病毒导致数据丢失。公司提供多层备份方案，员工应按数据重要程度选择合适的备份方式。

## 备份策略总览

| 数据类型 | 推荐备份位置 | 备份方式 | 保留周期 |
| --- | --- | --- | --- |
| 个人工作文档 | 个人网盘 H 盘（\\fileserver\home$） | 实时同步 | 30 天版本 |
| 部门协作文档 | 部门共享盘 S 盘 | 手动存放 | 30 天版本 + 每周全量 |
| 项目资料 | 项目盘 \\fileserver\project\项目编号 | 手动存放 | 项目周期 + 90 天 |
| 邮件 | Web 邮箱归档 | 自动归档 | 永久（按归档策略） |
| 移动办公临时文件 | 企业网盘（OneDrive 企业版） | 客户端同步 | 30 天版本 |

> 黄金原则：重要文件至少存在两份副本，且分别位于不同设备/位置。不要把唯一副本留在本地硬盘。

## 方式一：备份到个人网盘（H 盘）

1. 确认 H 盘已正确映射（参考《文件服务器访问》），在"此电脑"中可见 `H:`。
2. 将需要备份的文件夹拖入 H 盘对应目录，等待复制完成。
3. 大文件建议压缩后上传，减少占用带宽与配额。
4. 验证：到另一台公司电脑或通过 VPN 访问 `\\fileserver\home$\用户名`，确认文件可见且可打开。
5. 误删恢复：在 H 盘目录右键 →"属性 → 以前的版本"，选择时间点还原。

## 方式二：企业网盘同步客户端（OneDrive 企业版）

1. 浏览器访问 https://onedrive.company.com ，使用域账号登录。
2. 点击右上角"同步"按钮，下载并安装 OneDrive 客户端。
3. 登录后选择同步文件夹，默认路径 `C:\Users\用户名\OneDrive - StarTech`。
4. 将常用工作文件夹设为"始终保留在此设备上"（右键 → 始终保留）。
5. 文件修改后自动上传，状态栏图标显示：
   - 蓝色云朵：仅在线，未下载
   - 蓝色双箭头圆圈：同步中
   - 绿色对勾：已同步到本地
6. 版本历史：在网页端右键文件 →"版本历史记录"，可还原 30 天内任意版本。

## 方式三：邮件归档

1. 登录 Web 邮箱 https://mail.company.com 。
2. 设置 → 归档 → 启用"自动归档"，规则：
   - 收件箱中超过 6 个月的邮件自动移入"归档"文件夹。
   - 归档邮件不占用主邮箱 5GB 配额，单独提供 10GB 归档空间。
3. 手动归档：选中邮件 →"移动到 → 归档"。
4. 导出邮件：选中文件夹 →"导出 → PST 文件"，保存到 H 盘作为离线备份。

## 方式四：浏览器收藏夹与配置备份

1. Edge / Chrome 登录域账号后自动同步收藏夹、密码、扩展。
2. 手动导出：浏览器菜单 → 收藏夹 → 导出收藏夹为 HTML，存入 H 盘。
3. 重要账号的二次认证恢复码请保存到 H 盘加密文件中（不要明文存储）。

## 配置参数

- 个人网盘：`\\fileserver\home$\用户名`，配额 20GB，可申请扩容至 50GB
- 企业网盘：https://onedrive.company.com ，配额 1TB
- 邮箱归档：10GB，自动归档 6 个月以上邮件
- 文件版本保留：30 天（H 盘 / 企业网盘）
- 备份网络：建议在公司内网或 VPN 下进行大文件备份

## 常见问题

**Q1：备份速度很慢，怎么办？**
A：大文件备份建议在公司内网进行，速度可达 100MB/s；VPN 下受本地网络限制，建议在非工作时段进行。如内网仍慢，检查是否同时进行 Windows 更新或其他同步任务；H 盘单文件超过 1GB 请先压缩分卷。

**Q2：OneDrive 同步冲突，文件出现两份？**
A：多设备同时编辑同一文件会产生冲突副本。在客户端右键冲突文件 →"查看同步问题"，选择保留的版本，另一份会移入"冲突"文件夹。建议团队协作文件使用 OneDrive 在线共同编辑，而非本地编辑后同步。

**Q3：电脑硬盘坏了，本地数据能恢复吗？**
A：本地硬盘故障不在 IT 备份范围内。已同步到 H 盘、OneDrive 的文件可完整恢复；未同步的本地数据需送专业数据恢复，费用自理。强烈建议养成"文件先存 H 盘/OneDrive"的习惯。

**Q4：如何确认备份是否成功？**
A：H 盘备份——到另一台设备或网页访问确认文件存在；OneDrive——客户端图标为绿色对勾且网页端可见；邮件归档——"归档"文件夹中可见对应邮件。建议每月最后一个工作日做一次备份验证。
