# 邮箱客户端设置

适用场景：星辰科技员工在 PC、Mac 或手机上配置邮件客户端收发公司邮件。公司邮箱后缀为 `@company.com`，使用标准 IMAP/SMTP 协议，推荐使用 Outlook 或 Foxmail。

## 邮箱账号信息

- 邮箱地址：`firstname.lastname@company.com`（与域账号同名）
- 初始密码：由 IT 通过企业微信单独发送，首次登录后请立即修改
- 邮箱容量：5GB（含附件），达到 90% 会收到预警邮件
- Web 邮箱地址：https://mail.company.com

## 服务器参数

| 协议 | 服务器地址 | 端口 | 加密 |
| --- | --- | --- | --- |
| IMAP（收件） | imap.company.com | 993 | SSL/TLS |
| SMTP（发件） | smtp.company.com | 465 | SSL/TLS |
| POP3（不推荐） | pop.company.com | 995 | SSL/TLS |
| Web 邮箱 | mail.company.com | 443 | HTTPS |

> 推荐使用 IMAP，多设备邮件状态同步；不建议使用 POP3，避免邮件被本地独占收取导致其他终端无法查看。

## Outlook 配置步骤（Windows）

1. 打开"控制面板 → 邮件 → 显示配置文件 → 添加"，命名为 `Company`。
2. 打开 Outlook，选择"添加账户"，选"手动设置或其他服务器类型"。
3. 选择"POP 或 IMAP"，点击"下一步"。
4. 按下表填写账户信息：
   - 您的姓名：本人中文名
   - 电子邮件地址：`ming.zhang@company.com`
   - 账户类型：IMAP
   - 接收邮件服务器：`imap.company.com`
   - 发送邮件服务器：`smtp.company.com`
   - 用户名：`ming.zhang`（不带后缀）
   - 密码：邮箱密码
5. 点击"其他设置 → 发送服务器"，勾选"我的发送服务器要求验证"，选择"使用与接收邮件服务器相同的设置"。
6. 切换到"高级"选项卡，勾选"此服务器要求加密连接"，接收端口 `993`、发送端口 `465`，加密连接类型选 SSL/TLS。
7. 点击"下一步 → 完成"，Outlook 开始同步邮件，状态栏显示"已连接到 imap.company.com"即配置成功。

## Foxmail 配置步骤

1. 打开 Foxmail →"账号管理 → 新建 → 邮箱地址"，输入邮箱地址。
2. 选择"手动设置"，账户类型选 IMAP。
3. 接收服务器 `imap.company.com`，端口 993，SSL 打勾。
4. 发送服务器 `smtp.company.com`，端口 465，SSL 打勾。
5. 输入密码，点击"创建"，提示"账户创建成功"即完成。

## 移动端配置（iOS 为例）

1. 设置 → 邮件 → 账户 → 添加账户 → 其他 → 添加邮件账户。
2. 填写名称、邮箱、密码，点击"下一步"。
3. 选择 IMAP：
   - 收件主机名：`imap.company.com`
   - 发件主机名：`smtp.company.com`
   - 用户名：邮箱地址全称（`ming.zhang@company.com`）
4. 端口与 SSL：收件 993/SSL，发件 465/SSL（iOS 默认会自动识别）。
5. 点击"存储"，回到邮件 App 验证可收发。

## 常见问题

**Q1：发邮件报错"550 5.7.1 发件人未授权"？**
A：发送服务器未勾选身份验证，或用户名未填完整邮箱地址。请回到"其他设置 → 发送服务器"勾选要求验证，并将用户名改为 `ming.zhang@company.com`。

**Q2：能收邮件但发不出去？**
A：检查发送端口是否为 465 且加密为 SSL/TLS；部分家庭网络运营商会封 25 端口，请勿使用 25。如在公司外部，请先连接 VPN 再发件。

**Q3：Outlook 提示密码错误，但 Web 邮箱能登录？**
A：账号需要"应用专用密码"或开启"IMAP/SMTP 客户端授权"。登录 mail.company.com →"设置 → 客户端授权"，开启 IMAP/SMTP 服务并生成客户端专用密码，用该密码配置 Outlook。

**Q4：邮箱满了无法收件？**
A：登录 Web 邮箱清理"已删除"、"垃圾邮件"文件夹，并归档大附件邮件。长期方案：在 OA 提交"邮箱扩容申请"，附带部门主管审批。
