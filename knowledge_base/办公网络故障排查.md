# 办公网络故障排查

适用场景：星辰科技员工在使用有线或无线网络时遇到无法上网、网速慢、内网系统打不开等问题，可先按本指南自查；若无法解决再联系 IT 服务台。覆盖 Windows / macOS 两种系统。

## 故障快速定位流程

1. 确认问题范围：是单台设备还是周围同事都受影响？单个网站还是全部网站？内网（OA、文件服务器）还是外网（百度）？
2. 看物理连接：有线网线是否插紧、网口指示灯是否亮（绿灯/黄灯闪烁正常）；无线是否连到 `Corp-WiFi`。
3. 看本机状态：任务栏网络图标是否打叉或感叹号。
4. 按下方分类对照排查。

## 有线网络排查

1. 拔插网线两端，确认网口指示灯常亮或闪烁。
2. `Win + R` 输入 `ncpa.cpl` 打开网络连接，确认"以太网"未被禁用（如灰色，右键"启用"）。
3. 命令行执行 `ipconfig /all`，检查是否获取到 10.10.x.x 段 IP：
   - 若为 169.254.x.x：DHCP 未获取到地址，执行 `ipconfig /release` 后 `ipconfig /renew`。
   - 若 IP 正常但仍无法上网：执行步骤 4。
4. 测试连通性：
   - `ping 10.10.1.1`（网关）—— 通则本段网络正常，不通则网线/交换机口问题。
   - `ping 10.10.1.10`（DNS）—— 通则 DNS 可达。
   - `ping www.baidu.com`—— 通则外网正常；若提示"无法解析"，多为 DNS 问题。
5. 重置网络栈（管理员运行 PowerShell）：
   - `netsh winsock reset`
   - `netsh int ip reset`
   - 重启电脑后重新测试。

## 无线网络排查

1. 确认连接的是 `Corp-WiFi` 而非 `Corp-Guest`（Guest 仅能上外网）。
2. "忘记"已保存网络后重新连接，重新输入域账号密码。
3. 命令行执行 `ipconfig /all` 查看"无线局域网适配器"IP，应为 10.10.x.x 段。
4. 若提示"无法连接到此网络"：重启无线网卡（设置 → 网络和 Internet → 高级网络设置 → 禁用再启用 WLAN）。
5. 信号弱时切换到距离更近的 AP（无线接入点），办公区每 8 米一个 AP，避免被承重墙遮挡。

## 网速慢排查

1. 关闭下载工具、网盘同步、视频直播等高带宽应用。
2. 命令行执行 `ping 10.10.1.1 -t`（Ctrl+C 停止），观察延迟：
   - <10ms 且无丢包：本段网络正常。
   - 延迟波动大或丢包：可能 AP 负载过高或网线老化，请报修。
3. 切换有线测试对比：若有线正常、无线慢，则为无线问题；若两者均慢，可能是出口或服务器侧问题，请拨 8000 反馈。
4. 通过 https://speedtest.company.com 跑内网测速，正常带宽应 ≥50Mbps。

## 配置参数

- 内网 IP 段：10.10.0.0/16（DHCP 自动获取）
- 默认网关：10.10.x.1（x 为所在 VLAN）
- 主备 DNS：10.10.1.10、10.10.1.11
- 内网测速：https://speedtest.company.com
- 代理设置：浏览器与系统均不使用代理（自动检测关闭）

## 常见问题

**Q1：能上内网但不能上外网（百度打不开）？**
A：多为 DNS 配置错误或代理被误开启。检查"设置 → 网络和 Internet → 代理"，关闭"使用代理服务器"；命令行执行 `nslookup www.baidu.com`，若解析失败请将 DNS 手动改为 10.10.1.10。仍不行请联系 IT 检查出口策略。

**Q2：能上外网但内网系统（OA、文件服务器）打不开？**
A：说明可能误连到访客网络 `Corp-Guest`，请切换到 `Corp-WiFi`。有线用户确认网线插在办公位信息点（非访客口）。若 IP 不在 10.10.x.x 段，执行 `ipconfig /release` 和 `/renew`。

**Q3：网络图标显示黄色感叹号"无 Internet"？**
A：通常是 IP 冲突或 DHCP 异常。命令行执行 `ipconfig /release` → `ipconfig /renew`；或重启电脑。若 IP 显示 169.254.x.x 表示未拿到地址，尝试换一根网线或换一个网口测试。

**Q4：经常自动断网又重连？**
A：多为网卡省电模式导致。设备管理器 → 网络适配器 → 右键网卡 → 属性 → 电源管理，取消"允许计算机关闭此设备以节约电源"。无线用户请确认未连接到信号弱的远端 AP。
