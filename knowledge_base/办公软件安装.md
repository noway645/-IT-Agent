# 办公软件安装

适用场景：星辰科技员工在公司办公电脑上安装、激活、更新标准办公软件（Office 套件、PDF 工具、压缩工具、浏览器等）。公司通过"软件中心"统一分发授权软件，禁止私自下载安装未授权商业软件。

## 软件中心

公司所有标准办公软件通过"软件中心"统一分发与管理，软件中心已预装在所有公司电脑上。

1. 打开方式：开始菜单 →"StarTech 软件中心"，或桌面快捷方式"软件中心"。
2. 登录方式：自动使用域账号登录，无需输入密码。
3. 软件分类：办公套件、协作沟通、开发工具、安全软件、浏览器、其他工具。
4. 安装软件：在软件列表点击"安装"，软件中心自动下载并静默安装，安装完成后状态变为"已安装"。
5. 卸载软件：在"已安装"列表点击"卸载"，部分核心软件受策略保护不可卸载。

## Microsoft Office 安装

1. 打开软件中心 →"办公套件" → 选择"Microsoft 365 Apps 企业版"。
2. 点击"安装"，等待下载与安装（约 15–30 分钟，取决于网络）。
3. 安装完成后，首次启动 Word/Excel/Outlook：
   - 登录账户：使用域账号 `firstname.lastname@company.com`。
   - 系统自动识别企业许可证并激活，无需输入产品密钥。
4. 验证激活：打开 Word →"文件 → 账户"，显示"Microsoft 365 Apps 企业版 - 已由组织管理"即激活成功。
5. 更新：Office 自动更新，无需手动操作；如需强制更新，点击"更新选项 → 立即更新"。

## WPS Office 安装（替代方案）

1. 软件中心 →"办公套件" → 选择"WPS Office 企业版"。
2. 点击"安装"，按提示完成。
3. 首次启动 WPS，登录企业账号（域账号 SSO），自动激活企业授权。
4. WPS 与 Microsoft Office 文档格式兼容，可正常打开 .docx/.xlsx/.pptx。

## PDF 工具安装

1. 软件中心 →"其他工具" → 选择"Foxit PDF Editor 企业版"。
2. 点击"安装"，完成后启动。
3. 授权自动绑定域账号，无需激活码。
4. 主要功能：PDF 阅读、编辑、合并、转换（Word/Excel）、加签名、加水印。

## 压缩工具与浏览器

1. **7-Zip**：软件中心 →"其他工具" → 7-Zip → 安装。默认关联 .zip/.rar/.7z 等格式。
2. **Microsoft Edge**：Windows 自带，已配置公司策略与书签，无需另行安装。
3. **Google Chrome**：如业务需要，可在软件中心安装企业版，已配置公司代理与扩展白名单。

## 配置参数

- 软件中心服务器：sccm.company.com（IP：10.10.6.10）
- Office 授权：Microsoft 365 企业版（每用户 5 台设备）
- WPS 授权：WPS 企业版（域账号绑定）
- Foxit PDF 授权：Foxit PDF Editor 企业版
- 软件更新：软件中心每日检查，自动安装关键更新
- 个人软件安装：禁止安装未授权商业软件，个人需求请通过 OA 申请

## 常见问题

**Q1：软件中心打不开或一直转圈？**
A：检查网络是否在公司内网或 VPN 已连接；命令行 `ping sccm.company.com` 应解析到 10.10.6.10。若 ping 通但软件中心仍无响应，以管理员身份运行命令行，执行 `net stop ccmexec & net start ccmexec` 重启软件中心服务。仍无效请联系 IT 服务台 8000 重新注册客户端。

**Q2：Office 安装后无法激活，提示"无许可证"？**
A：确认登录账户为 `firstname.lastname@company.com`（非个人 Microsoft 账号）；退出其他个人 Microsoft 账户后重新登录。如显示"许可证已用完"，说明已在 5 台设备上激活，请登录 https://portal.office.com →"我的账户 → 已登录设备"注销旧设备。

**Q3：可以自己安装 PS、AutoCAD 等专业软件吗？**
A：不可以。专业商业软件需购买授权，私自安装盗版会触发火绒告警并由 IT 安全组追责。如工作需要，请在 OA 提交"软件授权申请"，注明软件名称、用途、使用人，由部门主管与 IT 审批后由 IT 安装授权版本。

**Q4：安装的软件被软件中心自动卸载了？**
A：公司终端策略会自动卸载未在白名单内的非授权软件（如个人版 360、迅雷等）。如该软件为工作必需，请先通过 OA 申请加入白名单再安装。可在软件中心"已卸载记录"查看卸载详情与原因。
