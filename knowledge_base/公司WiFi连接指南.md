# 公司 WiFi 连接指南

适用场景：星辰科技员工及访客在办公区域内连接公司无线网络，用于日常办公、邮件收发与内部系统访问。公司无线网络采用企业级 WPA2-Enterprise 加密，需使用域账号认证。

## 网络名称（SSID）

| SSID | 用途 | 认证方式 | 加密 |
| --- | --- | --- | --- |
| Corp-WiFi | 员工办公网络（推荐） | 域账号 + 密码（802.1x） | WPA2-Enterprise |
| Corp-Guest | 访客及临时接入 | 短信验证码 / 前台授权 | WPA2-PSK |
| Corp-Voice | IP 语音电话专用 | 自动绑定，请勿连接 | —— |

> 员工请优先连接 `Corp-WiFi`，访客如需上网请到前台登记获取 `Corp-Guest` 密码。

## Windows 10 / 11 连接步骤

1. 点击任务栏右下角网络图标，在 Wi-Fi 列表中选择 `Corp-WiFi`，勾选"自动连接"，点击"连接"。
2. 在弹出的认证窗口中填写：
   - 用户名：域账号（格式 `firstname.lastname`，例如 `ming.zhang`）
   - 密码：域登录密码（与开机、OA 登录一致）
   - 域：留空或填 `COMPANY`
3. 出现证书提示"继续连接吗？"时，点击"连接"。
4. 状态显示"已连接、安全"，浏览器打开 http://www.baidu.com 可正常访问即表示连接成功。

## macOS 连接步骤

1. 点击顶部菜单栏 Wi-Fi 图标，选择 `Corp-WiFi`。
2. 模式选择"自动"，点击"加入"。
3. 用户名填域账号，密码填域密码，点击"加入"。
4. 弹出"证书无法验证"时，点击"显示证书"→勾选"始终信任此证书"→"继续"。
5. 输入本机管理员密码确认后，Wi-Fi 图标变为实心扇形即连接成功。

## 手机连接（iOS / Android）

1. 设置 → Wi-Fi → 选择 `Corp-WiFi`。
2. 用户名、密码填写域账号信息；iOS 在"模式"中选择"自动"。
3. 证书弹窗点击"信任"。
4. 状态栏出现 Wi-Fi 标志，打开企业微信或浏览器验证连通性。

## 配置参数

- 认证协议：PEAP / EAP-MSCHAPv2
- 证书服务器：radius.company.com（CA：StarTech Internal CA）
- IP 分配：DHCP 自动获取，租期 8 小时
- DNS：10.10.1.10、10.10.1.11

## 常见问题

**Q1：提示"用户名或密码错误"但确认输入正确？**
A：检查是否误开启 Caps Lock；域账号不要带 `company\` 前缀或 `@company.com` 后缀，仅填 `firstname.lastname`。如近期修改过域密码，请先在公司电脑上登录一次让密码同步，再尝试连接。

**Q2：连接后无法访问内网系统（OA、文件服务器）？**
A：说明可能误连到 `Corp-Guest`，该网络仅能访问互联网。请"忘记"该网络后重新连接 `Corp-WiFi`。也可在命令行执行 `ipconfig /all`（Windows）确认获取到的 IP 是否为 10.10.x.x 段。

**Q3：访客如何上网？**
A：访客连接 `Corp-Guest`，浏览器会自动跳转到认证页面，输入手机号获取短信验证码即可上网，有效期 8 小时。如需更长时长，请联系接待部门通过 OA 提交"访客网络申请"。

**Q4：Mac 上反复提示输入密码？**
A：多为证书未信任。请进入"系统设置 → Wi-Fi → Corp-WiFi → 高级"，删除该网络后重新加入，并在证书弹窗中勾选"始终信任"。仍无效请联系 IT 服务台 8000 排查域账号状态。
