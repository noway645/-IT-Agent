## 📌 项目简介

在企业内部，员工常遇到 Wi-Fi 连接、VPN 配置、邮箱设置等重复性问题。传统方式需要 IT 人员逐一回复，效率低下。本项目设计了一个 **AI Agent**，员工只需用自然语言提问或下达指令，Agent 即可：

- 从私有知识库中检索答案（**RAG**）
- 自主调用工具完成操作（**Function Calling**）
- 结合上下文进行多轮对话（**Memory**）

全链路基于 **GLM-4.5-Air**（通过智谱 AI 开放平台），具备高性价比与良好的中文理解能力。

---

## ✨ 功能特性

- **🔍 RAG 知识库问答**  
  基于 Chroma 向量库，对 15+ 篇模拟 IT 文档进行语义检索，回答准确率显著提升。
- **🛠️ 工具调用**  
  Agent 可自主决定是否调用 `reset_password`（重置密码）或 `create_ticket`（创建工单）函数。
- **🧠 多轮对话记忆**  
  支持上下文理解与指代消解（例：“那李四也重置一下”）。
- **💻 友好的 Web 界面**  
  使用 Streamlit 搭建，开箱即用。
- **🔒 私有化部署友好**  
  仅需一个 API Key，无本地模型依赖，适合快速落地验证。

🎮 使用示例
知识库问答
用户：怎么连接公司 WiFi？
Agent：请打开电脑的无线网络设置，找到 “Corp-WiFi”，输入您的员工账号和密码即可连接。若无法找到该网络，请联系 IT 服务台。

工具调用 - 重置密码
用户：帮我重置张三的 OA 密码。
Agent：好的，正在为您重置张三的 OA 密码...
[调用 reset_password 工具]
Agent：已成功重置张三的 OA 密码，新密码已发送至其邮箱。

多轮对话
用户：帮我重置张三的 OA 密码。
Agent：已成功重置张三的 OA 密码。
用户：那李四呢？
Agent：已成功重置李四的 OA 密码，新密码已发送至其邮箱。

创建工单
用户：我的电脑一直蓝屏，能帮我提个工单吗？
Agent：好的，请描述一下蓝屏出现的具体场景（如开机时、运行特定软件时），我将为您创建工单。
用户：开机后几分钟就蓝屏。
Agent：已为您创建工单 #20250813-001，IT 支持人员将尽快联系您。
